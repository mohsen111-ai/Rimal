# Decisions

1. Phase 1 only: Fenix on a prebuilt GeckoView. No Gecko compile.
2. uBlock Origin ships bundled with strict lists and a balanced blocking mode
   (third-party frames and scripts blocked, with an allowlist of common CDNs and
   sign-in providers), tuned so ordinary sites still load.
3. This repo is a patch series plus overlay, not a mirror of mozilla-central.
4. Personal use, direct APK distribution, signed with the owner's own keystore.
5. App icon: cream-sun colourway (`design/icon/sahara-icon.svg`).
6. Name: Sahara. Mascot: Rimal the camel.
